# Project Instructions

Precision stop-loss / P&L calculator for futures (ES, NQ, CL, GC). Decimal-only math.
Three supported surfaces: `simple_dashboard.py` (Streamlit, primary), `stoploss` CLI (Typer),
`api/app.py` (FastAPI). Detailed agent guidance lives in `.github/copilot-instructions.md` —
this file covers the essentials and the non-negotiables.

## The Iron Rules (math)

1. **Decimal everywhere**: coerce every numeric boundary input with `Decimal(str(x))`.
   Quantize dollars to `Decimal("0.01")`, prices/distances to `Decimal("0.0001")`.
2. **Tick-round, then recompute**: stops must pass `contract.round_to_tick(...)` and all
   risk numbers must be recomputed from the *rounded* stop.
3. **Risk-first sizing** (user decision 2026-07-06, v0.3.0):
   `qty = min(floor(available_risk / risk_$_per_contract), floor(equity × leverage / (entry × point_value)))`.
   Never size off the leveraged notional; `risk_cash` (the risk budget) is a required input.
4. **Math-affecting changes** require a CHANGELOG entry under "Math-Affecting Changes"
   and regenerated `WORKED_EXAMPLES.md` numbers — generated by *running the code*
   (drive the API via TestClient), never hand-written.
5. Golden tests carry the hand math in their docstrings. New calculation logic cites
   its source (IRS / CME / EIA / NY Fed) in the module docstring.

## Build & Run

- Install: `pip install -e ".[dev]"`
- Dashboard: `streamlit run simple_dashboard.py` (or `.claude/launch.json` → `dashboard`)
- API: `python -m uvicorn api.app:app --reload`
- CLI: `stoploss size --help` / `stoploss pnl --help`

## Testing & Quality (all must pass before commit)

```bash
pytest tests/ -v --cov=src/stoploss --cov-fail-under=85
ruff check src/ tests/ api/ simple_dashboard.py
black --check src/ tests/ api/ simple_dashboard.py
mypy src/ --ignore-missing-imports
```

- Tests are class-grouped golden style; property tests use `hypothesis`.
- Mark tests hitting external APIs `@pytest.mark.slow` (skipped via `-m "not slow"`).

## Code Style

- Imports use the installed package: `from stoploss.… import …` (never `src.stoploss`).
  Entry scripts (`simple_dashboard.py`, `api/app.py`) keep a `sys.path` bootstrap so
  source checkouts run without installing.
- Line length 100 (ruff + black); ruff rules in `[tool.ruff.lint]`.
- Errors: raise `ValueError` with actionable messages in core modules; the API maps
  them to HTTP 400 (validate *before* the `try` so HTTPExceptions aren't swallowed);
  the dashboard shows `st.error`.

## Conventions

- Conventional commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`); `!` for breaking.
- SemVer; bump `pyproject.toml` + `src/stoploss/__init__.py` together (API reads it).
- UI follows `DESIGN.md` (light-first, monochrome + ocean-blue accent, flat borders).
