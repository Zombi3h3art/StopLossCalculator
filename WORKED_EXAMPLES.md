# Worked Examples: All 4 Contracts

Complete JSON examples for ES, NQ, CL, and GC trades with risk-first sizing, P&L, taxes, and margin interest.

> **Provenance**: Every request/response below was generated by running the actual
> API (`POST /size`, `POST /pnl`) — the numbers are code output, not hand estimates.
> Sizing is **risk-first**: `qty = min(floor(available_risk ÷ risk_$_per_contract),
> floor(equity × leverage ÷ (entry × point_value)))`.

## Example 1: ES Swing Trade (Long, §1256 Taxes)

**Scenario**: E-mini S&P 500 swing trade, 2-day hold, $2,500 risk budget on a $25k account at 12x declared leverage.

### API Request (Sizing)

```json
{
  "symbol": "ES",
  "side": "long",
  "entry": "5050.00",
  "account_equity": "25000.00",
  "leverage": "12",
  "pct_stop": "0.004",
  "risk_cash": "2500.00",
  "fees_open": "2.50",
  "fees_close": "2.50"
}
```

### Sizing Response

```json
{
  "success": true,
  "data": {
    "symbol": "ES",
    "side": "long",
    "qty": 1,
    "entry": "5050.00",
    "stop_price": "5029.75",
    "risk_per_unit": "20.2000",
    "risk_per_unit_actual": "20.2500",
    "risk_dollars_per_contract": "1012.50",
    "gross_exposure": "300000.00",
    "risk_cash": "2495.00",
    "fees_open": "2.50",
    "fees_close": "2.50",
    "slippage_open": "0",
    "method": "percent_stop",
    "buying_power_qty_cap": 1,
    "capped_by_buying_power": true
  }
}
```

**Interpretation**: The 0.4% stop lands at 5029.80 and is tick-rounded to **5029.75**
(20.25 points = $1,012.50 risk per contract). The $2,495 available risk budget would
afford 2 contracts, but $25k × 12 = $300k buying power only controls **1** ES contract
(~$252.5k notional each) — so qty is capped at 1 and max loss is $1,012.50.

### API Request (P&L with §1256)

```json
{
  "symbol": "ES",
  "side": "long",
  "entry": "5050.00",
  "target": "5100.00",
  "stop": "5029.75",
  "qty": 1,
  "fees_open": "2.50",
  "fees_close": "2.50",
  "slippage_open": "0.50",
  "slippage_close": "0.50",
  "energy_kwh": "0.2",
  "energy_cost_per_kwh": "0.14",
  "margin_loans": [
    {
      "loan_amount": "5000.00",
      "apr": "0.065",
      "days_held": 2
    }
  ],
  "tax_mode": "1256",
  "st_rate": "0.24",
  "lt_rate": "0.15"
}
```

### P&L Response

```json
{
  "success": true,
  "data": {
    "symbol": "ES",
    "side": "long",
    "qty": 1,
    "entry": "5050.00",
    "target": "5100.00",
    "stop": "5029.75",
    "gross_win": "2500.00",
    "gross_loss": "1012.50",
    "net_win_scenario": "2027.16",
    "net_loss_scenario": "-1020.34",
    "breakdown": {
      "fees_open": "2.50",
      "fees_close": "2.50",
      "slippage_open": "0.50",
      "slippage_close": "0.50",
      "total_fees_slippage": "6.00",
      "energy_cost": "0.03",
      "margin_interest": "1.81",
      "tax_on_win": "465.00"
    }
  }
}
```

**Interpretation**:
- **Win at 5100**: Gross $2,500, net **$2,027.16** after $6 fees/slippage, 3¢ energy, $1.81 margin interest, and $465 §1256 tax (blended 18.6% = 0.60×15% + 0.40×24%)
- **Loss at 5029.75**: Gross $1,012.50 + $7.84 costs = **−$1,020.34**
- **Risk/Reward**: ~1.99:1 net
- **Tax efficiency**: §1256 blended 18.6% vs 24% straight short-term saves $135 on this win

```json
{
  "symbol": "ES|NQ|CL|GC",
  "side": "long|short",
  "entry": "XXXX.XX",
  "account_equity": "XXXXX.XX",
  "leverage": "X",
  "pct_stop": "0.0XX",
  "risk_cash": "XXXX.XX",
  "fees_open": "X.XX",
  "fees_close": "X.XX"
```

## CLI Examples

### ES Sizing (percent stop, risk-first)

```bash
stoploss size \
  --symbol ES \
  --side long \
  --entry 5050 \
  --equity 25000 \
  --leverage 12 \
  --pct-stop 0.004 \
  --risk 2500 \
  --fees-open 2.5 \
  --fees-close 2.5
```

### ES Sizing (ATR stop)

```bash
stoploss size \
  --symbol ES \
  --side long \
  --entry 5050.10 \
  --equity 25000 \
  --atr 10.07 \
  --k-atr 2 \
  --risk 2010
```

### NQ P&L with §1256

```bash
stoploss pnl \
  --symbol NQ \
  --side short \
  --entry 18500 \
  --target 18450 \
  --stop 18555.50 \
  --qty 1 \
  --fees-open 3 \
  --fees-close 3 \
  --tax-mode 1256 \
  --st-rate 0.24 \
  --lt-rate 0.15
```

### CL with Energy + Margin Loan

```bash
stoploss pnl \
  --symbol CL \
  --side long \
  --entry 95.50 \
  --target 100 \
  --stop 93.11 \
  --qty 1 \
  --fees-open 5 \
  --fees-close 5 \
  --energy-kwh 0.35 \
  --loan1 3000:0.070 \
  --days 1 \
  --tax-mode 1256 \
  --st-rate 0.24 \
  --lt-rate 0.15
```
